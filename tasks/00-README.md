# 句子填空(mode 3)· 接力实施总览

**给用户看的**(不用发给 AI)。把任务拆成 5 步,每一步一个独立文件,可以交给不同的 AI(包括免费额度小的)。**每个步骤文件自带全部规则,AI 不需要看其他文件。**

## 一、步骤表

| 步骤 | 做什么 | 要附的源文件 | AI 的产物 | 做完后的项目状态 |
|---|---|---|---|---|
| **1** | 写 `make_cloze` 挖空函数 + 覆盖率检测脚本 | `memory/word_planner.py` | 改后的 `word_planner.py`、`tools/check_cloze.py` | 行为完全不变 |
| **2** | 调度规则:何时出填空题(**开关默认关闭**) | `memory/word_planner.py`(步骤 1 的产物) | 改后的 `word_planner.py`、`tools/test_step2.py` | 行为完全不变(开关关) |
| **3** | 后端:接收 mode 3、构造挖空、评判 | `api/word_routes.py`、`memory/word_progress_manager.py` | 两个改后的文件、`tools/test_step3.py` | 行为完全不变(没有 mode 3 的词) |
| **4** | 前端:渲染填空题 | `js/words.js`、`css/words.css` | 两个改后的文件 | 行为完全不变(没有 mode 3 的词) |
| **5** | 打开开关 + 端到端验证 + 更新 skill | `memory/word_planner.py`(步骤 2 的产物)、`SKILL.md` | 改后的 `word_planner.py`、`SKILL.md` | **功能正式上线** |

**顺序必须是 1 → 2 → 3 → 4 → 5**(3 和 4 之间可以互换)。每一步做完都可以先部署再继续,中途停下也不会坏。

> **最新版源文件在哪**:`memory/word_planner.py`、`memory/word_progress_manager.py`、`js/words.js` 请用我之前交付的**最新版**(已含 `hard_streak` 和麦克风复用的改动),不要用最初上传的旧版。`api/word_routes.py` 和 `css/words.css` 用你项目里现有的就行。

## 二、门槛:步骤 1 之后要你自己跑一次

步骤 1 会给你一个脚本 `tools/check_cloze.py`。**在你的服务器/电脑上**(能访问词库的地方)运行:
```
python tools/check_cloze.py
```
它会打印"有多少比例的词能成功挖空"。
- **≥ 50%**:继续步骤 2。
- **< 50%**:先停,把输出发给我,我来设计模糊匹配方案(AI 访问不到你的词库,所以只能你自己跑)。

## 三、怎么接力(每一步的操作)

1. 新开一个 AI 对话。
2. 先发下面的**接力提示词**,再把该步骤的 `.md` 文件内容贴进去,并**附上表里列的源文件**。
3. AI 做完后,把它产物放进项目对应位置,**运行它给的测试脚本**(`python tools/test_stepN.py`,应打印全部通过)。
4. 把 AI 回复末尾的「交接备注」存下来(下一步如果出问题,把它一起贴给新的 AI)。
5. 在下面的进度表打勾。

**接力提示词**(每次都用这一段):
```
你是接力实现者，正在给一个葡语学习网页的单词任务功能加新题型。
附件是一个「步骤文件」和需要修改的源文件。
要求：
1. 只做步骤文件里写的事，不要做别的步骤，不要重构，不要改命名。
2. 只阅读步骤文件里列出的文件；定位代码用 grep 锚点，不要信行号。
3. 源文件是 CRLF 换行，改完必须保持 CRLF。
4. 严格按步骤文件末尾的「交付格式」回复，最后附「交接备注」。
5. 回复要简短，不要复述需求，不要解释显而易见的东西。
```

### AI 的两种输出方式(步骤文件里写的"交付"按这个执行)
- **AI 能直接编辑/生成文件**:输出完整的改后文件。
- **AI 只能聊天**:只输出**被改动的函数**(完整的函数,不是整个文件),每段前面写清「文件名 + 函数名 + 是替换还是插入在哪个函数之后」。新建的文件(`tools/*.py`)必须完整输出。

## 四、出问题怎么办

| 情况 | 处理 |
|---|---|
| 某一步测试脚本没全部通过 | 把脚本输出 + 该步骤文件 + 当前源文件发给 AI,让它只修这一步 |
| 想回退上线的功能 | 把 `memory/word_planner.py` 里的 `CLOZE_ENABLED` 改回 `False`,重启即可,其余代码不用动 |
| AI 额度用完了中途停下 | 把它已经写好的内容保存,换一个 AI,贴同一个步骤文件 + AI 已改好的文件 + 一句"上一个 AI 做到了 X,请接着做剩下的" |
| AI 改动了步骤文件没提的东西 | 不要采用那部分改动 |

## 六、功能一句话说明(给你自己回顾用)

新增 **mode 3「句子填空」**:显示挖掉目标词的葡语例句 + 中文翻译 + 小提示,用户**只说缺的那个词**。只出给**复习词**,且只在词处于熟练度 box 3(再答对一次就"掌握")时出,所以一个词毕业前几乎必然过一次句子关;每天最多 6 题;句子里找不到目标词的自动退回普通题。
